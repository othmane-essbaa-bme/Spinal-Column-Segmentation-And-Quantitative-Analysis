# Spinal-Column-Segmentation-And-Quantitative-Analysis 
Spinal Column Segmentation & Quantitative Analysis ​This repository contains the medical imaging project focused on the segmentation of the human spinal column using 3D Slicer. ​Project Overview ​Objective: Accurate segmentation of the complete spine and isolation from surrounding rib cage structures. ​Software: 3D Slicer. ​Key Results: ​Total Segmented Volume: 503.95 mm³ ​Mean Bone Density: 472.7 HU ​Contents ​/data: Contains the segmented volume (.seg.nrrd) and the statistical report (.csv). ​/images: Visual documentation of the segmentation process.
